# Trilhas dos Biomas Brasileiros

Jogo de estudo sobre os 6 biomas brasileiros para o **7º ano**. Funciona no celular e no computador, até sem internet.

**Endereço:** https://jrsousa12.github.io/Biomas-Brasileiros/

## Como usar em sala
1. Passe o endereço aos alunos (QR code no quadro ajuda).
2. Cada aluno digita o nome e escolhe um bioma no mapa ou na lista.
3. Em cada trilha: lição (3 cartões) → 📖 "Quero ler mais" (texto completo) → quiz de 8 perguntas sorteadas.
4. Ao errar, o app mostra "📖 Reveja: <seção>" do texto.
5. No fim, o botão de relatório mostra acertos e pontos a rever. O aluno mostra a tela ou imprime/salva em PDF.

Também tem: Cartas de espécies, Mitos ou Verdades, Glossário, Ligar pares, Qual bioma?, Sequência e medalhas.

## Instalar como app (funciona offline)
- **Android / Chrome / Edge:** toque em "📲 Instalar app" ou no menu ⋮ → "Instalar app".
- **iPhone / iPad (Safari):** Compartilhar → "Adicionar à Tela de Início".

O progresso fica guardado **no próprio aparelho** (não há cadastro nem envio de dados).
